Publishing a real issue

  1. Leave the private formatting-only box unchecked and save the issue as a draft.
  2. In the pipeline, click Send test. This sends only to the Sender test group.
  3. After the test succeeds, reopen the issue, select scheduled, choose its Saturday, and save again.

If scheduling checks are incomplete, the issue will be saved safely as a draft so it still appears in the pipeline.
